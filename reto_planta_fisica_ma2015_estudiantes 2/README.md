# Planta Física · Reto mensual · MA2015.201

Construimos y explicamos un algoritmo genético para cuatro edificios con las demandas de marzo de 2025. Conservamos formulación, cálculos, código, resultados e interpretación en una libreta acumulativa.

## Comienza con la base común

1. Extrae los cinco archivos del ZIP en una misma carpeta.
2. Consulta la [guía del reto](guia_reto_planta_fisica.pdf) para identificar criterios, fechas y evidencias.
3. Prepara el entorno con Python 3.12–3.14 y `uv sync --locked`.
4. Abre Jupyter con `uv run jupyter lab` y abre [la libreta](reto_planta_fisica_solucion_minima.ipynb).
5. Reinicia el kernel y ejecuta de arriba abajo. Contrasta el cálculo manual con los resultados.
6. Integra la explicación de tu equipo y registra los cambios y la rotación en la misma libreta.
7. Conserva las salidas y entrega la versión acumulativa junto con los dos archivos de entorno, según la guía.

Los datos y el código están integrados. La capacidad de 1410 m³ y los límites por edificio son supuestos didácticos. Comparamos la base y una variación de mutación para interpretar los operadores y los resultados. La base proporcionada permite obtener 100 con comprensión y evidencia, conforme a la rúbrica.
